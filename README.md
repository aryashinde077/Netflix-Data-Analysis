# Netflix Data Analysis

## Project Overview
This project focuses on analyzing Netflix movies and TV shows to discover content trends, popular genres, country-wise distribution and release patterns using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Data Collection
2. Data Loading and Understanding
3. Data Cleaning
4. Handling Missing Values
5. Duplicate Removal
6. Exploratory Data Analysis (EDA)
7. Movies vs TV Shows Analysis
8. Content Ratings Analysis
9. Country-wise Analysis
10. Genre Analysis
11. Year-wise Content Trends
12. Movie Duration Analysis
13. TV Show Seasons Analysis
14. Data Visualization

## Key Insights
- Compared movies and TV shows available on Netflix.
- Identified the most common content ratings.
- Analyzed top countries and popular genres.
- Explored yearly content release trends.
- Examined movie durations and TV show seasons.

## Conclusion
This project provides insights into Netflix's content library through data analysis and visualization. It helped develop practical skills in Python, data cleaning, exploratory data analysis and data visualization.
